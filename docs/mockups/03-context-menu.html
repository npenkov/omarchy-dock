New Window = the item's launch action — desktop entry or exec, same path a plain click takes when nothing is running.
One row per open window when there's more than one (title, truncated). Click focuses that window.
For a pinned item this reads Unpin instead — if it's still running, the icon visibly hops back to the running section.
Dismissal — PopupWindow + HyprlandFocusGrab, the shell's own PopupCard pattern: any action closes it, clicking anywhere outside closes it, Esc closes it. It never persists. Auto-hide is suspended (held) while open, released on close.
